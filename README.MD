### Como compilar o trabalho
Para esse projeto, utilizados a biblioteca open-source `nob.h` criado por `Tsoding`. Logo, para compilar, primeiro faça a compilação do proprio `nob.c`:

`cc -o nob nob.c`

Obs: Ao inves de cc, pode-se utilizar qualquer outro compilador (Como `gcc`, `clang`, `cl.exe`, etc...).

Após fazer o `bootstrap` do nob. Basta chama-lo em seu terminal, como:

`./nob`

Agora, execute o arquivo na pasta `output`:

`./output/main`
